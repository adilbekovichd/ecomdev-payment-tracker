# Ecomdev — учёт оплат учебного центра

Мини-приложение для учёта учеников, платежей и задолженностей. Backend: Python 3.10+, FastAPI и SQLite. Веб-интерфейс адаптируется под телефон и компьютер.

## Запуск с нуля

```powershell
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

Откройте интерфейс на [http://127.0.0.1:8000](http://127.0.0.1:8000), а интерактивную документацию REST API — на [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs). База `data/payments.db` создаётся при первом запуске. Для другой базы задайте `DATABASE_PATH`.

## REST API

| Метод | Маршрут | Назначение |
|---|---|---|
| `POST` | `/students` | Создать ученика |
| `GET` | `/students` | Получить список учеников |
| `GET` | `/students/{id}` | Получить ученика |
| `PATCH` | `/students/{id}` | Изменить переданные поля ученика |
| `DELETE` | `/students/{id}` | Удалить ученика и его платежи |
| `POST` | `/payments` | Добавить платёж (`student_id`, `amount`, необязательная `paid_at`) |
| `GET` | `/students/{id}/payments` | История платежей ученика |
| `GET` | `/debtors?month=YYYY-MM` | Должники за месяц; если месяц опущен — текущий |

Суммы передаются десятичными числами и должны быть больше нуля. Дата платежа задаётся в формате `YYYY-MM-DD`. Долг равен месячной оплате минус сумма платежей ученика за выбранный календарный месяц; отрицательный долг не возвращается.
